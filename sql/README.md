# SQL files

- `tennis_queries_postgres.sql`: PostgreSQL schema, indexes, required queries, and dashboard queries.
- `tennis_queries_mysql.sql`: MySQL 8 equivalent.
- `load_postgres.sql`: PostgreSQL schema + CSV load script.
- `load_mysql.sql`: MySQL 8 schema + CSV load script.

Run the loaders from the project root (the folder that contains `sql/` and `data/`), as shown in the main README. The loaders read the CSVs from `data/`.
